# Dark Arisen ContentSource

This tree contains source art/data only. It is not runtime code and no Python from the DCC authoring process ships with the game.

- `.gltf` sources are authored for Unreal Engine 5.8 Interchange import.
- Gameplay authority remains native C++.
- `/Game/Alpha/...` assets are materialised only by an authorised UE 5.8 Editor/commandlet run.
- Source status is distinct from Unreal asset/runtime verification.
